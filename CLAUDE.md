# Texuguito - Seu Bot Amigo

Repo `meketreve/texuguito-seu-bot-amigo` (antes se chamava `chat-parade`). A pasta local e
o pacote Python também são `texuguito`. Juntou o overlay "chat parade" com o bot de pontos
do Texuguito original.

## Handoff entre sessões

- **No início de toda sessão:** leia `HANDOFF.md` antes de começar a trabalhar.
- **Antes de terminar qualquer sessão** (sempre, sem exceção): atualize `HANDOFF.md`
  com o estado atual, o que foi feito, os próximos passos priorizados, as decisões em
  aberto e as armadilhas encontradas. Reescreva o arquivo para refletir o estado
  atual — não acumule histórico de sessões antigas; remova itens já resolvidos.
  Atualize a data e o último commit de código no topo.
- Registre no handoff o que **não** foi verificado (testes que não rodaram, coisas
  testadas só num harness etc.), para a próxima sessão não assumir que está validado.
